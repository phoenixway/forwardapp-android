# Command Deck UX Analysis

This file contains analysis and recommendations for improving the Command Deck.

## Current Issues
- Overloaded with buttons
- Lack of prioritization
- No personalization
- Weak context awareness

## Recommendations
- Implement Basic/Pro modes
- Add contextual adaptation
- Allow personalization
- Improve quick capture

### **1. Два режими: Basic ↔ Pro**
- **Basic Mode** (для новачків та щоденного використання):
  - 4-6 великих кнопок з іконками та чіткими мітками:
    - "Додати завдання" (швидкий capture)
    - "План на день" (перехід до Today)
    - "Мої проєкти" (перехід до ієрархії)
    - "Пошук" (глобальний пошук)
    - "Налаштування" (тільки іконка)
    - "Імпорт/експорт" (згорнутий під меню)
  - Контекстне поле введення залишається на вершині.

- **Pro Mode** (для досвідчених користувачів):
  - Розгорнута панель з усіма поточними функціями + додаткові:
    - Групування за категоріями (Планування, Синхронізація, AI, Інструменти).
    - Швидкі клавіші (наприклад, довгий тап на кнопці "Додати завдання" відкриває меню з шаблонами).
    - Статистика за день (кількість завершених завдань, XP тощо).

**Перемикач режимів:** невелика кнопка "Pro" у верхньому правому куті або налаштування в профілі.

### **2. Контекстна адаптація**
Дека може змінюватися залежно від:
- **Часу доби**:
  - Ранок (6-10): акцент на план дня, цілі.
  - День (10-18): акцент на завдання, трекінг.
  - Вечір (18-22): акцент на ретроспективу, підготовку до завтра.
- **Дня тижня**:
  - Понеділок: акцент на тижневе планування.
  - П'ятниця: акцент на завершення тижня, звіт.
- **Активні контексти**:
  - Якщо активний контекст "Робота", показувати кнопки, пов'язані з робочими проєктами.

### **3. Персоналізація швидкого доступу**
- Додати режим "редагування" деки (тримання на кнопці → переміщення/приховування).
- Зберігати історію використання та автоматично піднімати найчастіші дії угору.
- Можливість створювати власні "швидкі дії" (наприклад, комбінація: "Додати завдання в контекст X з тегом Y").

### **4. Швидкий capture (головна функція)**
Контекстне поле введення має бути **центральним елементом** деки. Покращення:
- Підтримка natural language parsing ("завтра о 10 зустріч з командою #робота @проєктА").
- Швидкі шаблони (кнопки під полем: "Завдання", "Подія", "Нотатка").
- Інтеграція з AI для автоматичного тегування та призначення контексту.

### **5. "Живі" віджети**
Замість статичних кнопок – невеликі віджети, що показують стан:
- "Сьогодні: 3/8 завдань виконано"
- "Найближча подія: зустріч через 15 хв"
- "Активний контекст: Робота (2 год 30 хв)"

### **6. Прогресова розкриття AI функцій**
Зараз AI функції (чат, інсайти, life management) представлені як окремі кнопки, що може бути заплутано.
- Об'єднати під одніею кнопкою "AI Помічник" з меню:
  - "Запитати AI" (чат)
  - "Аналітика" (інсайти)
  - "План життя" (life management)
  - "Автоматизації" (майбутня функція)

### **7. Візуальна ієрархія**
- Використовувати розмір, колір та групування для підкреслення важливості.
- Basic Mode: великі кнопки з мітками.
- Pro Mode: компактні кнопки з іконками, можливість групування в секції.
