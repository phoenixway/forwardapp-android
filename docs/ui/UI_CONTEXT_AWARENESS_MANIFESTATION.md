# Як контекстна обізнаність проявляється в UI на даний момент

Контекстна обізнаність щодо життя та діяльності користувача проявляється в UI через кілька ключових компонентів:

## 1. **Екран стану життя (Life State Analysis)**
**Шлях:** `LifeStateScreen.kt` + `LifeStateViewModel.kt`

Це основний екран, де контекстна обізнаність відображається найбільш повно:

### **Відображення аналізу життя:**
- **Загальний аналіз (Summary)** - текстове резюме поточного стану життя користувача
- **Ключові процеси (Key processes)** - список основних активних процесів у житті користувача
- **Сигнали (Signals)** - розділені на позитивні та негативні сигнали з життя
- **Ризики (Risks)** - виявлені ризики з оцінкою серйозності (severity)
- **Можливості (Opportunities)** - виявлені можливості для покращення
- **Рекомендації (Recommendations)** - конкретні дії на 24-48 годин

### **Візуальні елементи:**
- **Заголовок з метриками** - відображає кількість позитивних/негативних сигналів, ризиків, можливостей, рекомендацій
- **Картки з можливістю згортання** - для кожної секції (сигнали, ризики тощо)
- **Індикатори завантаження** - під час аналізу даних
- **Кнопки дій** - "Copy Markdown", "Regenerate analysis", "Run in background"

## 2. **Чат з AI про стан життя**
**Шлях:** `LifeStateChatViewModel.kt` (інтегрований у `LifeStateScreen.kt`)

Контекстна обізнаність проявляється через інтерактивний чат:

### **Контекстна взаємодія:**
- **Автоматичне надання контексту** - при відкритті екрану, аналіз життя автоматично передається AI як контекст
- **Системний промпт** - включає поточний аналіз та рекомендації для AI
- **Швидкі підказки (Quick prompts)** - попередньо задані запити:
  - "Give me 3 steps for this week"
  - "How to reduce key risks now?"
  - "What can I delegate or postpone?"
  - "Plan for the next 48h"

### **Особливості UI:**
- **Потокове введення тексту** - AI відповідає з потоковим відображенням тексту
- **Аватари** - розрізнення повідомлень користувача та AI
- **Кнопка регенерації** - можливість перегенерувати відповідь AI
- **Контекстне меню** - регенерація з конкретного повідомлення користувача

## 3. **Екран AI-інсайтів (AI Insights)**
**Шлях:** `AiInsightsScreen.kt`

Контекстна обізнаність проявляється через автоматично згенеровані інсайти:

### **Типи інсайтів:**
- **Мотиваційні повідомлення** - для підтримки користувача
- **Інформаційні повідомлення** - факти про активність
- **Попередження** - про низьку активність або проблеми
- **Жарти** - для розвантаження

### **Контекстна генерація:**
- **Аналіз активності** - на основі записів активностей за сьогодні, вчора, останні 5 годин
- **Фокус-аналіз** - виявлення основних проектів, на які користувач витрачає час
- **Адаптивні повідомлення** - різні повідомлення в залежності від рівня активності

### **UI-елементи:**
- **Картки повідомлень** - з кольоровою кодуванняю за типом
- **Позначення прочитаних** - можливість відмітити повідомлення як прочитані
- **Кнопки видалення** - для кожного повідомлення
- **Очищення всіх** - кнопка "Очистити" в заголовку

## 4. **Контекстні дії та адаптація**

### **Адаптивні рекомендації:**
- **Персоналізовані дії** - рекомендації базуються на конкретному аналізі життя користувача
- **Пріоритети на 24-48 годин** - фокус на найближчих діях
- **Контекстні чеклисти** - дії з можливістю відмітки виконання

### **Контекстне копіювання:**
- **Копіювання в Markdown** - можливість експорту аналізу в структурованому форматі
- **Автоматичне форматування** - включає всі секції аналізу

## 5. **Фонові процеси та оновлення**

### **Автоматичний аналіз:**
- **Фонове оновлення** - можливість запустити аналіз у фоні
- **Кешування результатів** - збереження попередніх аналізів для швидкого доступу
- **Автоматична регенерація** - при зміні контексту або за запитом

## 6. **Візуальні індикатори стану**

### **Індикатори в реальному часі:**
- **Скелетон-картки** - під час завантаження даних
- **Індикатори прогресу** - лінійні та кругові індикатори
- **Анімації потокового введення** - для чату з AI
- **Кольорова кодування** - різні кольори для різних типів інформації

## **Поточні обмеження та можливості для покращення:**

1. **Обмежена інтеграція** - контекстна обізнаність в основному зосереджена на окремих екранах (Life State, AI Insights)
2. **Відсутність глобальної адаптації** - UI інших екранів не адаптується до контексту життя
3. **Пасивне відображення** - переважно показ контексту, а не активне використання для адаптації поведінки додатку
4. **Обмежена персоналізація** - рекомендації ще не інтегровані в основні потоки роботи додатку

## **Висновок:**

На даний момент контекстна обізнаність в UI проявляється **переважно через інформаційні екрани**, які:
- **Відображають** аналізований контекст життя користувача
- **Надають** рекомендації на основі цього контексту
- **Дозволяють** взаємодію з AI для отримання контекстних порад
- **Генерують** автоматичні інсайти на основі активності

Однак **активна адаптація UI/UX** на основі контексту (зміна інтерфейсу, пріоритезація функцій, контекстні підказки в основних потоках) ще не реалізована повною мірою. Контекстна обізнаність в основному використовується для **інформування та рекомендацій**, а не для **динамічної адаптації** інтерфейсу.
