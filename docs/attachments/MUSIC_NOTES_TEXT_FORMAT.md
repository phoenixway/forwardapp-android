# Формат текстової нотації для вкладення "Музичні ноти"

Цей документ описує **поточний (реально реалізований)** формат тексту для вкладення `MUSIC_NOTE`.

## 1. Коротко

- Редактор зберігає ноти як звичайний текст (`content`).
- Під час перегляду цей текст конвертується у MusicXML.
- Один "токен" (слово) = одна нота/пауза/директива/службовий маркер.

## 2. Ноти

Базовий шаблон ноти:

```text
<Літера><альтерація><тривалість><зсув_октави>
```

Де:

- `Літера`: `A B C D E F G` (регістр неважливий)
- `альтерація`: `#`, `b`, `##`, `bb` (опційно)
- `тривалість`: число `1|2|4|8|16|32` (опційно)
- `зсув_октави`: `+` або `-` (можна кілька: `++`, `---`)

Важливо:

- число після ноти **завжди** означає тривалість
- октава задається **тільки** через `@oct=...` та `+/-`

Приклади:

```text
@oct=4
C C4 C8 C16
F#4 Bb8 C#16+ A2-
```

## 3. Пауза

```text
R
R4
r8
```

`R`/`r` = пауза. Число після `R` — тривалість (такі ж значення: `1|2|4|8|16|32`).

## 4. Тривалості нот

- Без числа у ноті використовується значення за замовчуванням: `1/4`.
- `@dur=<значення>` змінює дефолтну тривалість для нот без числа.
- Якщо число в ноті/паузі є, воно має пріоритет над `@dur`.

Підтримані значення тривалості:

- `1`, `2`, `4`, `8`, `16`, `32`

Приклад:

```text
@oct=4 @dur=8
C D E F G A B C
R4 C8 D16 E16
```

У прикладі вище:

- `C` = C4, тривалість 1/8
- `R4` = пауза 1/4
- `D16` = нота тривалістю 1/16

## 5. Октава

- Базова октава: `@oct=<число>`
- Локальний зсув у токені: `+` / `-`

Приклад:

```text
@oct=3
C C+ C++ C-
```

## 6. Такт, розмір і роздільники

### Розмір

```text
@m=4/4
@m=3/4
@m=6/8
```

### Межа такту

```text
|
```

`|` закриває поточний такт і починає новий.

### Подвійна риска

```text
||
```

`||` ставить подвійний роздільник такту (double barline) і починає новий такт.

## 7. Як розділяти частини п'єси (куплет/приспів)

Практичний спосіб:

- мітки секцій через `{...}` (direction над тактом)
- або `^...` (текст над наступною нотою)
- візуальне відділення секцій через `||`

Приклад:

```text
@title="П'єса"
@composer="Автор"
@m=4/4 @oct=4 @dur=4

{[A] Куплет}
C D E F || G A B C |

{[B] Приспів}
C B A G || F E D C |
```

## 8. Текст і службові маркери

- Коментар рядка: рядок, що починається з `#` або `//`
- Текст над нотою: `^текст` (рядок або токен)
- Лірика: `_la la la` (слова розкладаються на послідовні ноти)
- Текст у фігурних дужках: `{текст}` як direction
- Inline-текст після ноти: `C{акцент}`

## 9. Що зараз не підтримується

- крапка тривалості (`C4.` у значенні dotted note)
- ліга/тай (`C~C`)
- акорди в одному часовому слоті
- repeat-структури (`:|`, `|:`), segno/coda

## 10. Повний приклад

```text
@title="Demo"
@composer="ForwardApp User"
@m=4/4
@oct=4
@dur=8

{[A] Intro}
^легато
_la la la la
C D E F || G A B C |

{[B] Verse}
R4 C8 D8 E4 || F8 G8 A8 B8 |
```
