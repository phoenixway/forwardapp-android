**Тема:** Впровадження комплексних інтеграційних тестів для Snapshot V2 з імітацією Room DB та складних зв'язків.

**Мета:** Гарантувати, що архітектура CrossRef не розсипається при складних сценаріях, а імпорт/експорт V2 працює детерміновано (без дублів та втрат).

**Завдання:**

#### 1. Створення інфраструктури тестування

* Використовуй `Room.inMemoryDatabaseBuilder` для створення реальної бази даних у пам'яті.
* Реалізуй `SyncTestEnvironment`, який дозволяє подавати JSON-рядки прямо в `MergeLocalDataSourceImpl` та `FullBackupLocalDataSourceImpl`, імітуючи файлову систему.

#### 2. Тестування складних CrossRef-структур

Реалізуй тести для перевірки «ланцюжка видимості»:

* **Сценарій "Багато до багатьох" (M:N):**
* Створи одну нотатку, прив'язану до **трьох різних контекстів**.
* Експортуй у Snapshot -> Очисти базу -> Імпортуй Snapshot.
* **Перевірка:** Переконайся, що нотатка відображається у всіх трьох контекстах (через `checklistDao.getChecklistsForContext`).


* **Сценарій "Dangling Links" (Сироти):**
* Спробуй імпортувати `CrossRefSnapshot`, для якого в бандлі **немає** відповідного `Attachment` або `Context`.
* **Перевірка:** Система не повинна падати. Вона має або ігнорувати такі записи, або коректно їх відфільтровувати, зберігаючи цілісність бази.



#### 3. Тестування крайніх випадків (Edge Cases)

Додай тести на наступні ситуації:

* **"The Duplicate Attack" (Детермінованість):**
* Імпортуй один і той самий бандл 3 рази поспіль.
* **Перевірка:** Кількість записів у таблиці `attachments` та `cross_refs` має залишатися незмінною (завдяки `nameUUIDFromBytes` та `OnConflictStrategy.REPLACE`).


* **"Empty Strings & Nulls":**
* Імпортуй нотатку з гігантським текстом (1 МБ) та нотатку з порожнім рядком `""`.
* **Перевірка:** Повне відновлення тексту без спотворень.


* **"Conflict Resolution (LWW)":**
* В базі лежить нотатка з `updatedAt` = 1000. В Snapshot бандлі та сама нотатка з `updatedAt` = 500.
* **Перевірка:** Версія з бази (новіша) має залишитися недоторканою.



#### 4. Валідація "Авто-зшивання" для Legacy V1

* Подай на вхід старий JSON, де у нотатки є `contextId`, але **немає** таблиці `attachments`.
* **Перевірка:** Чи з'явився після імпорту запис у `attachments`, який дозволяє UI «бачити» цю нотатку через `INNER JOIN`.

#### 5. Перевірка цілісності пунктів (Checklist Items)

* Імпортуй чек-ліст, де 50 пунктів.
* **Перевірка:** Чи всі 50 пунктів мають правильний `checklistId` після міграції, і чи не переплутані вони з пунктами іншого чек-ліста.

**Файли для роботи:**

* `SyncMapper.kt`
* `FullBackupLocalDataSourceImpl.kt`
* `MergeLocalDataSourceImpl.kt`
* `ChecklistDao.kt` / `NoteDocumentDao.kt`
* Нова папка тестів: `src/androidTest/java/com/romankozak/forwardappmobile/sync/integrity/`

**Очікуваний результат:** Набір тестів, що покриває 100% логіки CrossRef. Якщо хоча б один зв'язок між нотаткою та проектом розірветься — тест має «кричати».
